# M1 "It Boots" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a desktop shell that runs in a browser tab, where Notepad, built only on the public SDK, saves files that survive a reload.

**Architecture:** This is a pnpm monorepo.

- A Preact shell (window manager, taskbar, start menu, broker, trusted dialogs) runs on `http://localhost:5173`.
- Apps are built separately into `dist/apps/<id>/<version>/`. A tiny Node server on `http://127.0.0.1:5174` serves them with per-app CSP. This server stands in for the `ewapp://` protocol that comes in M1.5.
- Each app runs in an `<iframe sandbox="allow-scripts">`. It talks to the shell over a MessagePort, using the protocol in `@earlyweb/protocol`.
- Files go through a `FsBackend` interface. In M1 its only implementation is IndexedDB.

**Tech Stack:** TypeScript (strict), pnpm workspaces, Vite, Preact + @preact/signals, valibot, idb, Vitest (+ fake-indexeddb), Playwright, Biome, Node 22 `node:http`.

**Spec:** `PLAN.md` (sections 3–4 and §7 "M1"). Read §3.5–§4.6 before starting.

## Global Constraints

- Node ≥ 22, pnpm ≥ 9. TypeScript `strict: true`, ESM only (`"type": "module"`).
- Runtime dependencies are limited to `preact`, `@preact/signals`, `valibot` and `idb`. Dev dependencies: `vite`, `@preact/preset-vite`, `vitest`, `fake-indexeddb`, `@playwright/test`, `@biomejs/biome`, `typescript`, `concurrently`, `happy-dom`. Ask before adding anything else.
- The license is MIT. The `LICENSE` file's copyright line reads `Copyright (c) 2026 EarlyWeb contributors`.
- The shell origin is `http://localhost:5173` and the app origin is `http://127.0.0.1:5174`. Both are configurable through `VITE_APP_ORIGIN` / `SHELL_ORIGIN` env vars.
- The app iframe has exactly `sandbox="allow-scripts"`, `allow=""` and `referrerpolicy="no-referrer"`. Never add `allow-same-origin`.
- **Apps import nothing from the shell.** `apps/*` may depend only on `@earlyweb/sdk` and `@earlyweb/ui-kit`.
- `PROTOCOL_VERSION = 1` and `manifestVersion: 1`.
- All visuals are original. Don't use Microsoft/Apple/AOL logos, icons, sounds or bundled fonts. Font stacks may _name_ system fonts.
- Deviation from PLAN.md §3.7: the M1 `web` backend stores file contents as `ArrayBuffer` in IndexedDB, not OPFS. It's dev-only and replaced by Rust in M1.5. OPFS is deferred.

## Review Focus

1. **Dragging a window across another app's iframe:** the drag must continue smoothly and not stall when the pointer enters an iframe. Test: Task 14, `window.spec.ts`.
2. **An app that hangs or never answers close:** the user must still be able to close it ("(Not Responding)" plus End Task). Tests: Task 9, `lifecycle.test.ts`.
3. **Saving over an existing file:** "Save" in the save dialog must ask before replacing it. Test: Task 11, `save-validation.test.ts`.
4. **A flooding or malformed app:** it must not freeze the shell. Garbage messages are ignored and floods get `ERATE`. Test: Task 9, `broker.test.ts`.
5. **The browser window resized smaller than a window's position:** every window's title bar must stay reachable. Test: Task 6, `windows.test.ts`.
